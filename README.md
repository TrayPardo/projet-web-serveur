# Inventaire de boutique

Évaluation sommative 2 – Introduction à la programmation de serveurs Web  

## Sujet choisi : Sujet B - Inventaire de boutique

Une application pour gérer les produits d'une petite boutique. Elle permet de :
- afficher tous les produits ;
- ajouter un nouveau produit ;
- mettre un produit en promotion ou le retirer de la promotion ;
- supprimer un produit.

## Lancer le projet

1. Ouvrir un terminal dans le dossier du projet.
2. Installer les dépendances: `npm i`
3. Démarrer le serveur: `npm run dev`
4. Ouvrir le navigateur à l'adresse : http://localhost:5000

La base de données (`db/InventaireBoutique.db`) est créée automatiquement au premier démarrage, avec quelques produits de départ.

On peut ensuite ajouter, supprimer, mettre ou retirer un article en promotion
